# Glaze UI Wearables — Deferred Production Boundary

**Current shared authority:** GLAZE UI V1.6 / `1.6.0` Anchor  
**Lifecycle authority:** `registry/lifecycle.json`  
**Wearable status:** Deferred; no first-class wearable capability is currently promoted.

Wearable mappings prioritize glanceability, minimal interaction depth, large reachable targets, strong focus and selection state, low visual clutter, native platform conventions, accessibility, and efficient power use. A wearable surface is not a shrunken phone UI.

The repository retains Wear OS and watchOS reference source, build validation, manual emulator tooling, and an unaccepted native-evidence template as Development and audit provenance. Those artifacts do not expand the V1.6 Anchor capability set.

Wear OS, watchOS, and other wearable implementations require current exact-revision native evidence plus separate application acceptance for any claimed product target. Successful source validation, compilation, or emulator/simulator execution alone does not establish representative real-device, accessibility, packaging/signing, consumer, or production acceptance.

Before any future first-class wearable promotion, applicable evidence must cover the claimed target and scope, including native build/runtime behavior, display shape where applicable, touch and rotary or Digital Crown task completion, screen-reader and large-text behavior, Reduced Motion, transparency fallback, interruption/state restoration, performance and power behavior, packaging/signing where applicable, and representative real-device operation.

V1.7 remains Development and treats Wearable as a conditional qualification lane where claimed. This file does not establish V1.7 acceptance or alter current V1.6 Anchor authority.
