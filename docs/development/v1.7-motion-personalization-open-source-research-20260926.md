## GoreeCloud requirements derived from the research

1. Theme Manager may expose understandable motion-expression choices, but applications and theme packages must not gain raw timing, easing, spring, physics, distance, scale, or choreography controls.
2. The preference surface must preserve accessibility and authoritative performance precedence from Motion Expression Profiles dev.21.
3. A theme package may request an approved semantic motion profile for preview, but it must not include executable animation code, modules, scripts, keyframes, or remote animation resources.
4. Theme-package requests must never silently override an authoritative user selection, persist a preference, or auto-apply a preference.
5. The current Personalization 2.0 durable `motionIntensity` vocabulary remains authoritative. Section 30 must not silently create a second persistence authority.
6. Because the current durable vocabulary has only `minimal`, `standard`, and `expressive`, the additional Theme Manager **Minimal** presentation mode must remain preview-only until a distinct authoritative durable encoding is explicitly designed and migrated.
7. Applying a persistable choice requires explicit user intent; Glaze only proposes the durable value and never persists it itself.

## Independent GoreeCloud design

The Section 30 source layer exposes four governed Theme Manager presentation choices:

- **Minimal** — strongest optional-motion reduction, preview-only in dev.22 because no distinct durable encoding exists.
- **Calm** — maps to Personalization 2.0 `motionIntensity=minimal`.
- **Balanced** — maps to Personalization 2.0 `motionIntensity=standard`.
- **Expressive** — maps to Personalization 2.0 `motionIntensity=expressive`.

The layer delegates effective motion behavior to the dev.21 Motion Expression Profiles resolver, so Reduced Motion, Simplified Visual Effects, and authoritative performance pressure still reduce optional richness without rewriting the selected preference. Direct manipulation remains tracked.

Theme packages are semantic requesters only. An authoritative package declaration plus an explicit preview request may preview one of the governed modes when no authoritative user selection is present. A package cannot persist, auto-apply, override a user selection, or carry executable animation behavior.

This research record documents engineering influence only. No upstream source code, exact motion values, curve definitions, component implementation, or distinctive third-party visual identity is reproduced.
