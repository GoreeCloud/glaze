# Glaze UI V1.7 dev.40 — Expression System Core

**Lifecycle:** Development  
**Plan binding:** V1.7 plan v1.3, Section 48  
**Stable baseline:** GLAZE UI V1.6 / 1.6.0  
**Consumer eligible:** No

## Implemented source scope

The bounded dev.40 tranche implements the **Expression System Core** requirement group:

- Semantic Geometry.
- Supporting, Standard, Prominent, and Hero visual emphasis.
- Expressive Typography.
- Semantic Containment.
- Component Expression.
- Governed Expression Resolution.

The resolver consumes semantic intent instead of unrestricted raw geometry, typography, spacing, color, material-effect, animation, performance, ranking, or acceptance values.

Visual prominence does not create semantic severity. Hero presentation therefore does not imply critical, dangerous, protected, private, successful, or other provider-owned state.

Accessibility outranks optional expression. Large Text, Reduced Motion, Reduced Transparency, Increased Contrast, and Forced Colors may reduce or reshape optional richness while task continuity, semantic meaning, direct manipulation, and authoritative state remain preserved.

Personalization may change expression. **Personalization must not change truth.**

## Still planned

Glaze Contextual Actions, Glaze Brief, Glaze Control Center, Glaze Workspace, Glaze Compact Surface, Glaze Agent Activity, Glaze Privacy Attention, Glaze Accessibility Presentation, Glaze Creative Surface, Glaze Compare, and Glaze Care Surface remain planned.

## Acceptance boundary

Section 48 is incomplete. dev.40 is source implementation only and does not establish rendered, native-platform, assistive-technology, representative-device, Large Text/reflow, Forced Colors, measured-performance, energy, cross-platform-expression, or human visual acceptance.

The existing dev.39 V1.7 acceptance-control framework remains bound to the v1.2 plan and does not automatically accept v1.3 Section 48 requirements.

This tranche does not change VERSION, V1.6 Anchor authority, V1.7 consumer eligibility, deployment acceptance, or production acceptance.
