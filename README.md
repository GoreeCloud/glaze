# Glaze V1.7

**Glaze V1.7 / `1.7.0` is GoreeCloud's current Official Anchor and Stable-compatibility shared design and experience system.**

Machine version: **1.7.0**. Canonical repository: **GoreeCloud/glaze**.

## Current release boundary

V1.7.0 is a deliberately bounded stabilization release. Its public runtime, `js/glaze-v1.7.0.mjs`, inherits the already accepted GLAZE UI V1.6 / `1.6.0` runtime behavior.

The retained `1.7.0-dev.47` aggregate and the Section 48 Expression System / Adaptive Intelligence implementation are **not** imported by the Stable runtime. They remain Development source and are carried forward through **Glaze V1.7.1**.

This preserves GoreeCloud's fail-closed rule: missing qualification evidence is not converted into a pass by a lifecycle decision.

## What moved to V1.7.1

All unfinished or unverified V1.7 Development obligations moved out of the V1.7.0 Stable runtime. The retained open qualification boundary includes frame pacing, input latency, claimed form factors/devices, keyboard/pointer/touch/alternative input, representative rendering, native behavior, performance, energy, regression, human visual/motion review, assistive technology, privacy boundaries, security boundaries, and Section 48 acceptance.

The existing 16 evidence-group-complete retained lanes remain exact-source provenance for their historical reviewed source. They are not silently rebound to later V1.7.1 revisions.

## Privacy and security

No unverified dev.47 privacy or security behavior is shipped by the V1.7.0 Stable runtime. V1.7.1 cannot reach Stable while an applicable privacy or security requirement remains incomplete or unverified.

## Predecessor and rollback

GLAZE UI V1.6 / `1.6.0` is the immediate known-good rollback baseline and remains immutable historical release evidence. Its controlled tag, GitHub Release, security acceptance, artifact digests, and publication readback remain valid provenance for that release.

## Consumer boundary

Promotion of the shared design system does not automatically make any GoreeCloud application conformant or production-ready. Every applicable consumer must target `1.7.0` and complete fresh repository-local acceptance for its supported runtime, platforms, accessibility, privacy/security integration, rollback, release, and production boundary.

## Development provenance

Historical V1.7 dev.1–dev.47 identifiers remain immutable provenance. They are not renamed to V1.7.1. The V1.7.1 wrapper establishes the new successor line while retaining those historical source references.

See `docs/v1.7/GLAZE_V1_7_PLANNED.md` and the V1.7 qualification records for the detailed Development history.
