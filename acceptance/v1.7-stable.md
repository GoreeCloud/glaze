# Glaze V1.7 / 1.7.0 — Bounded Stable Acceptance

**Version:** `1.7.0`  
**Lifecycle target:** Stable compatibility channel / canonical Anchor  
**Stable baseline:** `1.6.0`  
**Owner scope decision:** 2026-10-03  
**Public runtime entrypoint:** `js/glaze-v1.7.0.mjs`

## Decision

Glaze V1.7 / `1.7.0` is accepted only for the bounded Stable scope defined by `contracts/v1.7/stable-scope.json`.

The Stable V1.7 runtime intentionally inherits the already accepted `js/glaze-v1.6.0.mjs` behavior and does **not** import or expose the retained `1.7.0-dev.47` Development aggregate as Stable behavior. The release delta is therefore release identity, current-baseline authority, and successor-track bookkeeping rather than unverified presentation or authority behavior.

This scope decision does not convert missing evidence into passing evidence.

## V1.7.1 transfer

The retained V1.7 Development source remains valuable implementation provenance, but every unfinished or unverified obligation attached to that source is moved out of the V1.7.0 Stable scope and into the separately versioned V1.7.1 Development/hardening track.

The following retained qualification lanes move to V1.7.1:

- Frame pacing
- Input latency
- Mobile
- Tablet
- Desktop
- Foldable
- TV
- Wearable
- Keyboard
- Pointer
- Touch
- Alternative input
- Representative rendering
- Native behavior
- Performance
- Energy behavior
- Regression
- Human visual and motion review
- Assistive technology
- Privacy boundaries
- Security boundaries

Section 48 Expression System and Adaptive Intelligence acceptance also moves to V1.7.1. Its existing source-complete implementation remains Development-only until the applicable exact-revision evidence is accepted.

## Privacy and security boundary

No unverified V1.7 Development privacy or security behavior is included in the V1.7.0 Stable runtime. The Stable runtime inherits the accepted V1.6.0 behavior and authority boundary.

Accordingly, the unverified dev.47 Privacy boundaries and Security boundaries lanes are not deferred mandatory requirements for behavior shipped by V1.7.0; the affected Development behavior itself is excluded from this Stable scope and transferred to V1.7.1. V1.7.1 cannot become Stable while an applicable privacy or security requirement remains unverified.

## Explicit non-claims

V1.7.0 Stable does not claim:

- acceptance of any `1.7.0-dev.47` presentation or adaptive-intelligence feature;
- Section 48 acceptance;
- new native-platform or physical-device acceptance;
- new representative performance or energy acceptance;
- new assistive-technology acceptance;
- new rendered-regression acceptance;
- new privacy/security acceptance for dev.47 behavior;
- automatic downstream consumer conformance;
- deployment or product production acceptance;
- immutable tag or GitHub Release publication merely from repository lifecycle promotion.

## Rollback

The immediate known-good rollback baseline remains GLAZE UI V1.6 / `1.6.0` using `js/glaze-v1.6.0.mjs`.

## Follow-up

All transferred work is controlled by `GLAZE_V1_7_1_HARDENING.md` and the V1.7.1 Development entrypoint. Historical V1.7 dev.1–dev.47 provenance remains immutable and must not be relabeled as evidence for a different source revision.
